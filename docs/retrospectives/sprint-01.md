Day 3 — Database schema. Six migrations authored in dependency order, all using UUID v4 primary keys via a project-local trait (HasUuidPrimaryKey) rather than calling Laravel's Str::uuid() ad-hoc in controllers. ADR-0001 records the UUID strategy and the conditions under which it should be reconsidered (>5M rows, query-plan bottleneck, or real-time analytics requirement). One scope extension noted: a fourth behavioral_events.event_type enum value (rapid_zone_transition) was added beyond the three documented in §3.3 of the AT2 report. This reflects implementation-level refinement of the Zone-Based Logic — the three documented event types remain canonical; the fourth is an internal distinction between sustained pacing and rapid zone-crossing. To be explained in the AT4 review chapter under "scope refinements during implementation". One denormalisation also noted: current weight, BMI, and BMR are stored on the pets table as well as in health_records, write-time updated by the application layer to avoid an expensive read-time subquery. Defensible and documented.
